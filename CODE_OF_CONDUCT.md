# Code of Conduct

Snails is an open-source project. Everyone participating in issues, pull requests, discussions, and community channels is expected to follow this code.

## Expected behavior

- Be direct about code and ideas, and respectful to the person.
- Assume good intent, but accept correction when the effect of a message was harmful.
- Keep criticism technical and specific: what broke, where, and what would fix it.
- Respect different experience levels. “Read the manual” is not a substitute for an answer.

## Unacceptable behavior

- Harassment, threats, personal attacks, or discriminatory language.
- Sexualized language or imagery in project spaces.
- Publishing someone’s private information without consent.
- Sustained disruption of issues, discussions, or reviews.
- Retaliation against someone who reports a problem.

## Scope

This code applies in the repository, issue tracker, discussions, chat channels, and project events, and when someone represents the project in public.

## Reporting

If you experience or witness unacceptable behavior, contact the repository maintainers through GitHub and ask for a private channel. If the report involves a maintainer, use GitHub’s report abuse flow instead. Reports are handled as confidentially as the platform allows.

## Enforcement

Maintainers may remove comments, close issues, or block accounts that violate this code. Enforcement decisions are explained to the people involved where possible. A maintainer who is part of a report does not decide its outcome.
